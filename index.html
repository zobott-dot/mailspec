Quick Start

MailSpec calculates weight, thickness, and postal classification for direct mail assemblies. Here's how to build your first assembly.

1

Choose a template

Click a category button in the Add Template row — Envelopes, Self-Mailers, Folds, Booklets, Inserts, or Cards. A dropdown reveals the available formats. Click one to add it to your assembly.

2

Adjust dimensions and stock

Templates pre-fill dimensions and paper stock. Adjust any value to match your actual spec. The stock dropdown is searchable — just start typing. For irregular folds, toggle Custom Panels to set flat size, finished size, and layer count independently.

3

Review results

The right panel updates automatically with total weight, thickness, postal classification, postage estimates, and risk warnings when values approach USPS boundaries. Self-mailer assemblies also show tab compliance status. On mobile, tap Results.

4

Finalize and share

Set weight and thickness buffers in Global Adjustments (default 5%). Add tab seals for self-mailers. Use Copy or Export on the BOM table, or click the print icon for a clean one-page spec sheet.

Good to know

  • Your work auto-saves to your device.
  • Use Configs to save and name assemblies for later.
  • Booklet templates include self-cover and plus-cover options with separate cover stock.
  • The Folds category includes accordions, Z-folds, gate folds, roll folds, iron crosses, and French folds.

rocket_launch Getting Started

What This Tool Does

MailSpec Pro calculates the weight, thickness, and postal classification of direct mail assemblies. Choose from template categories — envelopes, self-mailers, folds, booklets, inserts, and cards — to quickly build assemblies. The tool estimates postage costs, checks self-mailer compliance against USPS standards, warns when values approach postal boundaries, and generates printable spec sheets.

Basic Workflow

1
Add Components

Use the Add Template category buttons to select from common formats — envelopes, self-mailers, folds, booklets, inserts, and cards. Each category dropdown shows the available presets.

2
Configure Each Piece

Set dimensions, select paper stock, choose fold type, and add coatings or seals. Calculations update automatically.

3
Review Results

Tap the Results tab (mobile) or view the right panel (desktop) for totals, postal class, postage estimates, and tray capacity.

4
Export or Save

Use Copy/Export buttons for job tickets. Save configurations via the Configs button. Your work auto-saves to your device.

⚠️ Important Note

This tool provides estimates for planning purposes. For critical postal qualification, always verify with physical samples on a calibrated scale.

🔒 Tab Seals (Global Adjustments)

Self-mailers require tab seals to meet USPS automation standards. Set seal type and quantity in Global Adjustments. The total thickness and weight from seals is added to the assembly total.

Wafer Tab

Standard 1" clear circular tab. Most common. +0.002" / +0.003 oz each.

Glue Dot

Fugitive adhesive dots that release cleanly. +0.004" / +0.001 oz.

Line Glue

Continuous glue line along fold edge. +0.001" / +0.002 oz.

Note: USPS requires tabs based on piece weight and fold configuration. Consult DMM 201.3.15 for specifics.

Custom Panel Mode

For irregular folds where panels aren't equal (gate folds, roll folds, iron crosses, etc.), toggle Custom Panels on any self-mailer, insert, accordion, or booklet. This lets you specify independently:

Flat Size

Total paper area — drives weight calculation

Finished Size

Folded dimensions — drives postal classification

Layers at Fold

Sheets at thickest point — drives thickness

Use Specialty Folds templates for common configurations with Custom Panels pre-configured.

Postal Risk Warnings

The results panel automatically warns when assembly values approach USPS classification boundaries. Each warning shows how much room remains before the boundary.

Advisory

Approaching a boundary. Informational.

Caution

Very close. Adding components could trigger a reclassification.

Violation

Boundary crossed. Classification has changed.

Monitors thickness, weight, dimensions, and aspect ratio. Only warns about the next relevant boundary.

Self-Mailer Compliance (DMM 201.3.14)

When a self-mailer component is present, MailSpec evaluates tab requirements based on fold type and weight per USPS DMM 201.3.14. The compliance panel shows whether the current seal configuration meets requirements.

Bi-fold/Tri-fold up to 1 oz: 2 tabs, 1" minimum
Bi-fold/Tri-fold over 1 oz: 2 tabs, 1.5" minimum
Quarter-fold over 1 oz: 3 tabs, 1.5" minimum
With die-cuts/perforations: adds a third tab to the requirement

Check the "Has die-cuts/perforations" box in the compliance panel if your piece has optional design elements. Maximum weight for folded self-mailers is 3 oz.

Print Spec Sheet

Click the print icon in the header to generate a clean, one-page specification sheet. The printout includes assembly summary, postal classification, postage estimates, warnings, compliance status, the full BOM table, and seal/buffer notes. Formatted for letter-size paper with typographic hierarchy — no screen UI elements.

Data Confidence Indicators

Each stock entry shows provenance information below the stock selector:

Source badge — clickable link to manufacturer spec sheet (when available)
Tolerance — color-coded: green (±3%), gray (±5%), amber (±7%+)
Verified date — turns amber after 12 months, red after 24 months
Custom stocks — marked "Unverified" in purple italic

Flat: Exceeds letter, max 12"H × 15"W × 0.75"
Parcel: Exceeds flat dimensions
